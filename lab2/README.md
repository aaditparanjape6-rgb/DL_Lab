# Lab 2 - Multilayer Perceptron

## Objective

To implement and study a Multilayer Perceptron (MLP) neural network for classification using deep learning techniques.

## Contents

- `multilayer_perceptron.ipynb` - Implementation of a Multilayer Perceptron.
- `lab_2.ipynb` - Implementation, training, evaluation, and visualization of the neural network model.

## Topics Covered

- Data preprocessing
- Neural network architecture
- Multilayer Perceptron
- Model training
- Training loss
- Validation accuracy
- Confusion matrix
- Model evaluation

## Tools and Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow / Keras

## Results

The model was trained and evaluated using classification metrics, including accuracy and a confusion matrix. Training loss and validation accuracy were also visualized to analyze model performance.

## How to Run

1. Open either `.ipynb` file in Jupyter Notebook or VS Code.
2. Install the required Python libraries.
3. Run the notebook cells sequentially.
4. Observe the training results, accuracy, loss curve, and confusion matrix.
